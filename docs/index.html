Discovery

GET/map/:anilistIdTry it ↗

Look up the AniList title ID across supported catalog identifiers and return the available ID mapping.

/map/16498
GET/episodes/:anilistIdTry it ↗

Fetch episode lists from all supported sources for an AniList title ID.

/episodes/16498
GET/episodes/:provider/:anilistIdTry it ↗

Fetch episodes from one or more selected sources. Chain source slugs in the path; use ?map=false to skip the ID-map lookup.

/episodes/anikoto/16498
/episodes/anikoto/animegg/16498?map=false

Streams

GET/watch/:provider/:anilistId/sub|dub/:provider-:episode

Resolve an episode into its available stream sources. Use the episode ID returned by the selected provider’s episode list.

/watch/anikoto/16498/sub/anikoto-1
/watch/animegg/16498/sub/animegg-1
/watch/aniwaves/16498/sub/aniwaves-1
Quick start: request /episodes/16498, select an episode ID from a source, then pass that ID to its matching /watch route. Responses are JSON.
