API routes.

Three scraper sources. Request episode data, then use the matching provider route to resolve a stream. Responses are JSON.

BASE_URL=

01 / discovery

GET/map/:anilistIdtry ↗

Look up the AniList title ID across supported catalog identifiers.

/map/16498

GET/episodes/:anilistIdtry ↗

Fetch episode lists from all three sources for an AniList title ID.

/episodes/16498

GET/episodes/:provider/:anilistIdtry ↗

Limit the request to one or more providers. Set ?map=false to skip ID mapping.

/episodes/anikoto/16498
/episodes/anikoto/animegg/16498?map=false

02 / streams

GET/watch/:provider/:anilistId/:audio/:provider-:episode

Resolve an episode using its provider-specific episode ID from the episode response.

/watch/anikoto/16498/sub/anikoto-1
/watch/animegg/16498/sub/animegg-1
/watch/aniwaves/16498/sub/aniwaves-1

Quick start: request /episodes/16498, choose an episode ID, then pass it to the matching /watch route.
